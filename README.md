# 《专注时刻 (Focus Time)》开发实现说明文档

## 一、 项目概览
本仓库已基于《专注时刻 PRD v1.0》与《Nord 暗色设计规范与组件样式说明》，完整实现生产级番茄钟计时、响应式交互、任务工时归集及离线数据统计系统。

## 二、 核心架构设计

### 1. 核心状态机与计时引擎 (`src/timer-engine.js`)
- **状态流转**：严密遵循 `IDLE` -> `RUNNING` -> `PAUSED` -> `COMPLETED` -> `REST_WAITING` 五态状态机闭环。
- **抗休眠与防漂移**：基于真实物理时间戳（`targetEndTime = Date.now() + remainingSeconds * 1000`）实时校准，规避浏览器切后台节流和设备休眠时钟停滞风险；支持页面重新加载后断点自动恢复。
- **模式流转**：
  - 番茄专注（Pomodoro, 25m）
  - 短休息（Short Break, 5m）
  - 长休息（Long Break, 15m）
  - 每连续完成 4 个番茄周期自动建议进入长休息（15m）。

### 2. 动态环形进度条 (`src/progress-ring.js`)
- 基于原生 SVG `stroke-dasharray` 与 `stroke-dashoffset` 动态偏移绘制。
- 动态注入 Nord 风格发光滤镜（`drop-shadow`），跟随不同模式语义色平滑过渡。

### 3. 数据持久化与统计看板 (`src/storage.js`)
- **任务管理**：任务创建、下拉关联绑定、删除、累计番茄数与耗时秒数自动自增归集。
- **今日战报**：实时计算今日完成番茄数、累计专注时长（分钟）。
- **趋势分析**：近 7 日每日专注时长柱状走势图、各任务专注时长占比分布。
- **离线持久化**：采用 `localStorage` 并内置 `MemoryStorage` 兼容无浏览器 DOM 测试环境。

### 4. 声光提醒与通知 (`src/notifications.js`)
- **Web Audio API**：合成 Nord 风格清脆高纯度正弦波三和弦铃声（番茄完成：C5-E5-G5；休息结束：A4-C5-E5）。
- **系统通知**：接入系统原生桌面通知，并在权限受限时自动平滑降级为应用内 Toast 悬浮横幅。
